Таблицы

HTML-таблицы позволяют организовывать данные (текст, изображения, ссылки) в виде строк и столбцов.

Для создания таблицы используется тег <table>.

Основные теги таблицы

  • <table> - контейнер для всей таблицы.
  • <tr> (Table Row) - строка таблицы.
  • <td> (Table Data) - ячейка данных (обычная ячейка).
  • <th> (Table Header) - заголовочная ячейка (обычно жирный шрифт и по центру).
                
                    <table>
                        <tr>
                            <th>Имя</th>
                            <th>Возраст</th>
                        </tr>
                        <tr>
                            <td>Алексей</td>
                            <td>25</td>
                        </tr>
                        <tr>
                            <td>Мария</td>
                            <td>30</td>
                        </tr>
                    </table>

Группировка содержимого

Для лучшей семантики и стилизации таблицу можно разделить на части:

  • <thead> - заголовок таблицы (шапка).
  • <tbody> - основное содержимое (тело).
  • <tfoot> - подвал таблицы (итоги).
  • <caption> - название таблицы (пишется сразу после открывающего тега <table>).
                
                    <table>
                        <caption>Список сотрудников</caption>
                        <thead>
                            <tr>
                                <th>Отдел</th>
                                <th>Имя</th>
                            </tr>
                        </thead>
                        <tbody>
                            <tr>
                                <td>IT</td>
                                <td>Иван</td>
                            </tr>
                        </tbody>
                        <tfoot>
                            <tr>
                                <td>Всего</td>
                                <td>1 сотрудник</td>
                            </tr>
                        </tfoot>
                    </table>

Объединение ячеек

Для объединения ячеек используются атрибуты:

  • colspan="n" - объединяет n столбцов (по горизонтали).
  • rowspan="n" - объединяет n строк (по вертикали).
                
                    <table>
                        <tr>
                            <th colspan="2">Заголовок на 2 столбца</th>
                        </tr>
                        <tr>
                            <td rowspan="2">Ячейка на 2 строки</td>
                            <td>Обычная ячейка</td>
                        </tr>
                        <tr>
                            <td>Обычная ячейка</td>
                        </tr>
                    </table>

CSS-свойства для таблиц

Границы таблицы

По умолчанию таблицы отображаются без границ (или с двойными границами в старых браузерах).

  • border - задаёт рамку для table, th и td.
  • border-collapse - управляет отображением границ соседних ячеек.
    • collapse - границы схлопываются в одну.
    • separate - границы разделены (по умолчанию).
                
                    /* Стандартный стиль таблицы */
                    table {
                        width: 100%;
                        border-collapse: collapse; /* Убирает двойные линии */
                    }
                    
                    th, td {
                        border: 1px solid #ddd; /* Тонкая серая рамка */
                        padding: 8px; /* Внутренний отступ */
                    }

Отступы и выравнивание

  • padding - внутренний отступ внутри ячеек (задаётся для th и td).
  • text-align - горизонтальное выравнивание текста (left, center, right).
  • vertical-align - вертикальное выравнивание (top, middle, bottom).
                
                    th {
                        text-align: left; /* Выравнивание по левому краю */
                        padding-top: 12px;
                        padding-bottom: 12px;
                        background-color: #4CAF50; /* Зелёный фон */
                        color: white; /* Белый текст */
                    }
                    
                    td {
                        text-align: center; /* Текст по центру */
                        vertical-align: middle; /* По вертикали по центру */
                    }

Полосатые таблицы и ховер-эффект

Используйте псевдоклассы для улучшения читаемости.

                
                    /* Чётные строки серые */
                    tr:nth-child(even) {
                        background-color: #f2f2f2;
                    }

                    /* Подсветка строки при наведении */
                    tr:hover {
                        background-color: #ddd;
                    }

Адаптивность таблиц

Таблицы плохо масштабируются на мобильных устройствах. Для решения этой проблемы таблицу часто оборачивают в контейнер с прокруткой.

                
                    .table-container {
                        overflow-x: auto; /* Горизонтальная прокрутка если не влезает */
                    }
